# 移除 EasyCon 排除功能设计

## 目标

从 auto-swsh-rng 的 App 和项目自有适配代码中移除明确不需要的 EasyCon
功能：远程运行、远程停止、编译烧录、清除烧录、固件生成，以及只服务于这些
功能的帮助、设置和测试。测试不得创建真实消息框或访问真实烧录设备。

## 保留范围

保留自动化真正需要的串口发现与连接、Switch 按键和摇杆、等待与可取消动作
序列、输入录制、采集卡、截图、模板/OCR 识别和通知能力。保留脚本编辑与本地
运行兼容行为时，不得重新引入固件或远程设备操作。

## 实现边界

- `EasyConTabControl` 不再创建或绑定烧录页、固件按钮、远程运行/停止按钮、
  烧录自动运行设置，以及固件/烧录/脚本语法/ESP32 帮助入口。
- 删除仅供这些入口使用的委托、方法、常量和固件文件生成逻辑。
- `EasyConScriptAdapter` 删除固件汇编 API 与固件结果模型；保留格式化、编译
  和无界面脚本求值能力。
- App 测试改为断言排除入口不存在；删除对已移除行为的复刻测试。
- 能力矩阵继续将这些项目标记为“排除”，并补充“App 不暴露入口”的证据。

## 验证

先添加失败测试证明排除入口仍存在，再实现最小删除。最终运行 solution 构建、
Core、Upstream、CLI、App 测试以及无界面 CLI smoke。构建和测试期间不得显示
任何交互式消息框。
