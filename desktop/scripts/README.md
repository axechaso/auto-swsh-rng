# 剑盾脚本适配

这 9 份脚本由用户提供。`originals/` 按字节保留原始 `.txt`，脚本库载入同名 `.ecs` 适配版；保留原稿里的作者署名和说明。

## 使用

在「伊机控 → 脚本库 / 执行」载入脚本，填写左侧参数，然后点击「检查脚本」。
`填入这里` 是必填占位符，不是 ECS 表达式；不会自动代入测试值。
修改后的脚本可另存为 `.ecs`，参数值会写入保存副本。

搜图模板尚未随脚本提供。补齐后选择原伊机控 `ImgLabel` 目录（或其上级目录），也可以把它放在脚本同目录。
点击「共通设置 → 保存」会同时保存所选模板目录。运行前检查缺失模板和采集画面，缺少依赖时不执行脚本按键。

## 适配改动

- 全部裸数字等待改为显式 `WAIT`，保留原按键顺序和时长。
- 原地过帧：初始化累计计数器 `$5`；处理只过一次和整 60 次批次的退出边界；恢复菜单使用独立 `$12` 计数，避免覆盖 `$1` 的摇杆延迟。
- 精准过帧：先把负的日期差取正，再进入 `FOR`，修复负次数直接跳过操作。界面校验扣除预留帧和天气误差后的帧数。
- 雷雨自行车：日期同步后直接以同步月 / 日计算差值，修复差值为负时把当前位置越算越远的问题。
- 卡对战 bug：纯搜图等待循环增加 100 毫秒间隔。
- 5 份包含测种的脚本用字符串累计结果，结束后一次输出 128 位序列，避免旧版 `PRINT ... & \` 的续行差异。

## 验证范围

自动化测试使用模拟手柄、模拟标签结果和跳过真实等待的执行器。
覆盖 9 份脚本正常结束、128 位测种输出、原地过帧 1 / 2 / 61 / 62 / 121 次、恢复后的延迟保持和负日期差循环。
这些检查验证解析、分支和计数，不验证 Switch 菜单位置、联机时机、真实帧数、天气或图像匹配效果。
原脚本的菜单前提、日期推进规则、识别阈值与设备延迟仍需补齐标签后实机校准。
